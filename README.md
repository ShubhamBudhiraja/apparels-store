# Apparel Store

A modern e-commerce web application built using **React, Next.js, Redux, Node.js, and Express**. Features include **product browsing, cart and wishlist management, secure payments via Juspay, and order tracking**. The backend is deployed on Vercel using a serverless architecture.

## 📦 Tech Stack
Frontend:

-> React

-> Next.js

-> Redux Toolkit

-> Axios

-> Bootstrap

Backend:

-> Node.js

-> Express.js

-> Express Validator

-> MongoDB

-> Juspay Integration (Payments)

Deployment:

-> Vercel (Backend)
